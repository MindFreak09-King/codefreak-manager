# CodeFreak SSH Manager

Simple SSH Manager for VPS with expiry system.

## Features
- Create SSH Account
- Bulk Account Creation
- Delete Account
- Extend Expiry
- Change Password
- Restart SSH
- Reboot VPS

## Installation

```bash
git clone https://github.com/YOURUSERNAME/codefreak-manager.git
cd codefreak-manager
chmod +x install-codefreak.sh
sudo ./install-codefreak.sh
